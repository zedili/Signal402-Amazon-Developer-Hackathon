Seven checks. One safe payment.

Each transition is explicit, validated, and written to a hash-chained audit log.

  1. 01Discover

    Request resource and receive HTTP 402.

  2. 02Validate

    Pin price, payee, network, and timeout.

  3. 03Policy

    Apply budget and trusted-payee rules.

  4. 04Approve

    Ask the human only when required.

  5. 05Sign

    Keep the private key in the wallet.

  6. 06Settle

    Verify, retry, and prevent replay.

  7. 07Audit

    Return receipt and protected result.

# Contributing

1. Fork the repository and create a focused branch.
2. Run `npm install` and `npm run check` before opening a pull request.
3. Add tests for every state transition or security rule you change.
4. Never commit keys, wallet secrets, personal data, or production payment payloads.
5. Explain how the change preserves the non-custodial trust boundary.

By contributing, you agree that your contribution is licensed under MIT.
